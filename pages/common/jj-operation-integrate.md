# jj operation integrate

> Make an operation part of the operation log in a `jj` repository.
> See also: `jj operation abandon`, `jj operation diff`, `jj operation log`, `jj operation restore`, `jj operation revert`, `jj operation show`.
> More information: <https://docs.jj-vcs.dev/latest/cli-reference/#jj-operation-integrate>.

- Integrate an unintegrated operation into the operation log:

`jj {{[op|operation]}} integrate {{operation_id}}`
